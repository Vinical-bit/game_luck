# Luck's Arcade

Mini jogo em pixel art com o Luck. HTML, CSS e JavaScript puros, sem build e sem dependências.

## Como rodar
Abra o `index.html` no navegador, ou sirva a pasta: `python3 -m http.server` e acesse http://localhost:8000

## Estrutura
- `index.html`: estrutura da página
- `style.css`: visual de fliperama
- `script.js`: sprite do Luck (desenhado em canvas), itens, jogo e sons

## Controles
- Arrastar o dedo/mouse no Luck: cafuné
- Tocar fora dele ou setas/A/D: mover
- Botões: CARINHO, PETISCO, JOGAR (chuva de itens), LATIR

A fonte Press Start 2P vem do Google Fonts (precisa de internet; sem ela cai numa fonte monoespaçada).
